**Perchance Chat** is an Android Webview Wrapper for perchance.org's simple AI Chat & Roleplay. This app is a modified version of **Assistral** (https://github.com/shano/assistral).

**This app was modified using Apktool with following key changes:**
```
1. Changed package name.
2. Changed app name.
3. Removed the original app icon and left it empty.
4. Substituted the original URLs meant for Mistral to that of Perchance's.
5. Nothing else has been changed so far.
```
